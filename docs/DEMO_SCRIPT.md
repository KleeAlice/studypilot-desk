# 演示脚本

1. 双击 `start.bat`，完成中文首启：选择当前周、主题和学习偏好。
2. 在“今日驾驶舱”查看当前阶段门、周交付契约；输入“完成一段可验收的 Python 数据处理练习”并添加任务。
3. 切到“24 周路线”，查看 W1-W24、六阶段、G1-G6、验收与补救信息。
4. 在“知识网络”添加两个节点和一条先修边；尝试反向连边，展示环拒绝。
5. 在“资料书架”导入一份 PDF/DOCX/MD/TXT，搜索正文关键词并查看真实片段。
6. 在“Python 实验室”运行 `print(sum(range(10)))`，再运行死循环观察超时或点击停止。
7. 在“复盘与求职”完成一个测验，查看掌握度与复习队列变化。
8. 在“项目与研究”记录一个项目/论文/实验条目，刷新页面确认持久化。
9. 在“设置”切换主题并创建备份。
10. 关闭窗口；再次启动，确认设置、任务和记录仍在，且没有额外后端窗口或端口冲突。
