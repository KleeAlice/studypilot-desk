# StudyPilot Desk v0.2.0

StudyPilot Desk 0.2.0 将桌面运行时迁移到 Tauri 2，并保留既有的本地优先学习工作流与数据兼容性。

## 本次发布

- 使用 Tauri 2 与 Rust 替换 Electron 桌面壳，降低安装包与运行时开销。
- 由 Rust Actix-Web 统一调度桌面本地 API；服务只监听 `127.0.0.1`，每次启动生成会话令牌。
- Python 保留为不监听 TCP 端口的私有领域 Worker，继续支持资料解析、学习功能与 Python 实验室。
- React 工作台保持课程书架、资料阅读、知识画布、学习助手、统计、实验室和备份功能。
- 资料阅读器与 Word 预览库改为按需加载，降低首次进入工作台时的前端包体。

## 安装与升级

1. 从本 Release 的 Assets 下载 Windows NSIS 安装包。
2. 运行安装程序并按提示完成安装。
3. 已有用户可直接安装新版本；应用会保留本地 SQLite 数据，并在迁移前创建恢复点。

Windows 未签名构建可能出现 SmartScreen 提示。请仅下载本仓库发布的文件。

## 验证

本发布链包含 TypeScript 类型检查、Vitest、Python 3.10/3.12/3.14 测试、Rust fmt/Clippy/workspace tests、Playwright Web E2E、依赖审计、CodeQL 和 Windows NSIS 打包。

## 已知限制

- Python 实验室运行本机代码，提供资源边界但不是操作系统级安全沙箱；不要执行不受信任的脚本。
- macOS 与 Linux 构建在未配置代码签名或公证密钥时为未签名构建。
- Android/iOS 尚未完成 SDK、模拟器与真机兼容性验证。

更多功能范围与限制见 [产品范围](../PRODUCT_SCOPE.md) 和 [已知限制](../KNOWN_LIMITATIONS.md)。
