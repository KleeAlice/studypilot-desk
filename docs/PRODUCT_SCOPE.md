# 产品范围

## 产品目标

把“阅读路线文档”转成每天可执行、可验收、可复盘的学习操作系统。核心对象不是页面，而是 `路线 → 任务 → 证据 → 知识点 → 测验 → 掌握度 → 复习` 的本地数据闭环。

## P0 交付状态

| 范围 | 状态 | 说明 |
|---|---|---|
| Electron 桌面壳与生命周期 | 完整闭环 | 无边框、单实例、随机端口、会话令牌、窗口状态、关窗清理 |
| 首启、课程与 24 周路线 | 完整闭环 | 中文引导、新建/切换独立课程、W1-W24、六阶段、G1-G6、阶段验收/补救 |
| 今日任务与证据 | 完整闭环 | 新增、状态、优先级、周关联、证据持久化 |
| 知识网络 | 完整闭环 | 自由画布、概念/便签/记忆/引用卡、拖动/缩放/适合视野、三类关系、删除、环拒绝、复习反馈 |
| 收集/笔记/导图 | 完整闭环 | 画布便签与思维分支可视化编辑；通用富文本和导出能力仍有限 |
| 文档解析与检索 | 完整闭环 | PDF/DOCX/MD/TXT、去重、FTS5/BM25、片段；阅读器交互较基础 |
| Python 实验 | 完整闭环 | 安全环境发现与选择、IDE 工作台、草稿/撤销、独立进程、超时、停止、截断、测试、历史与运行快照 |
| 测验/掌握度/复习 | 完整闭环 | 确定性评分、Beta-Binomial、错因与间隔队列 |
| 项目/研究/论文/实验/错误/面试/周复盘 | 基础闭环 | 页面入口与统一 CRUD 存储存在；专用表单、指标与自动联动未全部深化 |
| 备份恢复与设置 | 完整闭环 | ZIP 清单/校验、恢复点、主题和路径设置 |

“完整闭环”表示存在实际存储、API、界面或系统行为及自动化测试；“数据/基础闭环”表示信息可长期保存与取回，但尚未达到专业垂直工具的交互深度。

## 非目标与优先级边界

- P1 未纳入本次完成口径：向量检索、混合召回/RRF、重排器、外部 AI 提供商、全局剪贴板快捷键、悬浮专注窗、Git/LSP/调试器深度集成、隐藏测试、Matplotlib 图形回传、作品集生成、EPUB。
- P2 未纳入：云同步、多端协作、插件市场、移动端、团队管理和远程执行。
- 不提供互联网暴露、多用户权限或恶意代码执行环境。

## 核心成功指标

- 用户可以从周路线创建一项任务，提交证据，并在重启后继续。
- 文档内容可被真实解析并全文搜索，不使用伪结果。
- 代码运行失败、超时、停止和输出过大均有明确状态。
- 学习结果能改变知识点掌握度并生成后续复习。
- 窗口关闭后其 FastAPI 子进程不可访问。
