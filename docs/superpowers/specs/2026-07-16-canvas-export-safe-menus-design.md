# 画布导出、专注模式与安全操作菜单设计

## 目标

让当前知识笔记可以完整导出为 PNG、PDF、Word 与 Markdown，并提供软件内专注全屏；同时消除课程书架和知识笔记书架中“三点按钮单击即删除”的高风险交互。

## 交互设计

- 画布工具栏增加“导出”菜单。PNG/PDF 是当前笔记的完整画布快照，不受当前缩放和平移影响；Word/Markdown 按卡片的纵向、横向位置排序，整理标题、类型、正文、资料来源与关系清单。
- 导出文件先由本地 FastAPI 生成，再通过 Electron 原生保存对话框选择路径；浏览器环境保留 Blob 下载回退。
- “专注全屏”覆盖应用内容区域但保留桌面窗口边界，避免操作系统级全屏打断；顶部保留笔记名与“退出专注”，Esc 随时退出。
- 三点按钮只打开操作菜单。菜单中的“移入回收站”是一次明确选择，随后弹出带对象名称与后果说明的二次确认。取消、点击外部或 Esc 均不改动数据。

## 输出语义

- PNG：带浅色点阵背景、关系连线、彩色卡片、正文与图片缩略图的完整画布。
- PDF：与 PNG 同布局的单页画布 PDF，按实际内容边界生成页面。
- Word：A4 文档，包含课程/笔记标题、按空间顺序整理的卡片章节、图片和关系附录。
- Markdown：单文件、自包含；图片转成 data URI，避免移动文件后失效。

## 安全与边界

- 导出只允许 `png`、`pdf`、`docx`、`md`，文件名净化，桌面写入限制为受控扩展名且限制 64 MB。
- 后端按 course/notebook 双重作用域读取，已删除或跨课程笔记返回 404。
- 空画布仍能导出带标题的有效文件。
- 删除动作保持现有软删除/回收站语义，不增加永久删除入口。
