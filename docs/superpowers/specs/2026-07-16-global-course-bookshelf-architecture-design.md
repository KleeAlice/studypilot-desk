# StudyPilot 全局课程书架与课程工作区设计

日期：2026-07-16

## 1. 目标

把课程从“知识网络里的一个笔记本”提升为整个学习系统的最高业务层级。应用启动后先进入全局课程书架；打开课程后先进入课程主页，再访问驾驶舱、路线图、知识网络、资料库、Python 实验室和复习中心。课程内的知识网络继续包含多个独立笔记、导图和自由画布。

本次改造要解决三个核心问题：

1. 当前书架只挂在知识网络内部，用户进入主驾驶舱前看不到课程空间。
2. 当前依赖隐式 `active_course`，界面不能从路径和层级上清楚表达数据归属。
3. “课程”“笔记本”“画布”概念混用，无法自然扩展为一门课程多个专题知识笔记。

## 2. 产品层级

应用分为两个清晰层级。

### 2.1 全局课程层

路径为 `/courses`，只承载跨课程能力：

- 课程书架；
- 搜索、筛选和排序；
- 新建课程；
- 继续上次学习；
- 回收站；
- 全局设置；
- 数据备份与恢复。

默认启动到课程书架。全局设置提供“启动时继续上次课程”开关；开启后恢复该课程最后访问的模块，关闭后始终回到书架。

### 2.2 单课程工作区

路径统一为 `/courses/:courseId/*`。打开课程后先进入 `/courses/:courseId/home`，左侧课程导航包括：

- 课程主页；
- 主驾驶舱；
- 学习路线；
- 知识网络；
- 资料库；
- Python 实验室；
- 练习与复习；
- 课程设置。

课程工作区左上角固定提供“返回课程书架”，并持续显示课程封面、名称和当前模块。切换课程后回到新课程主页，避免保留上一门课程的页面语境。

## 3. 全局课程书架

### 3.1 布局

书架不是普通卡片网格，而是应用级欢迎空间：

- 顶部：StudyPilot 品牌、全局搜索、设置、回收站；
- 首屏主区域：问候语、“继续上次学习”大卡片、创建课程按钮；
- 下方：按更新时间排列的课程书本；
- 工具栏：全部、进行中、已完成、最近学习，支持名称/更新时间/进度排序；
- 空状态：用课程创建引导取代空白页面。

课程书本显示封面、课程名称、简介、学习进度、今日待办数、知识笔记数、最近学习时间。单击选中，双击或点击“进入课程”打开；更多菜单提供编辑、复制、移入回收站。

### 3.2 动效

- 书本按 40–70ms 间隔依次入场；
- 悬停时轻微上移、书脊展开并显露进度；
- 打开课程时封面向右翻开，工作区从书页内部过渡；
- 返回书架时反向收拢到原书本位置；
- 搜索和筛选采用布局过渡，不闪烁重排；
- 尊重系统 `prefers-reduced-motion`，降级为淡入淡出。

动效只解释层级和状态，不阻塞操作；常规过渡控制在 160–320ms，首次打开课程最多 520ms。

## 4. 新建课程

采用可跳过的两步轻量向导。

### 第一步：课程身份

- 课程名称（必填）；
- 简介；
- 封面颜色/渐变；
- 图标；
- 可选封面图片。

### 第二步：学习计划

- 学习目标；
- 预计学习周期；
- 每周投入时间；
- 起始日期；
- 可跳过并稍后在课程设置中完善。

创建成功后进入课程主页。系统同时生成空的课程路线、资料目录和默认知识笔记集合，但不强制创建具体画布。

## 5. 课程主页

课程主页是模块总入口，不等同于原有主驾驶舱。它回答“我现在学什么、从哪里继续”：

- 顶部课程封面、目标、整体进度和连续学习天数；
- “继续学习”主按钮，恢复该课程最后一次具体活动；
- 今日任务、下一里程碑和临近复习；
- 模块入口卡：路线图、知识网络、资料库、Python 实验室、练习与复习；
- 最近打开的知识笔记、资料和实验；
- 学习活动时间线。

主驾驶舱仍保留深度数据、周计划和统计；课程主页负责导航和续学，避免重复。

## 6. 知识网络与多笔记

进入课程的知识网络后先展示该课程的知识笔记集合。这里不再展示其他课程。

### 6.1 笔记集合

支持创建以下文档：

- 自由画布；
- 思维导图；
- 混合笔记（便签、图片、文本引用和节点关系）；
- 后续可扩展模板，但首版不增加模板市场。

每个知识笔记拥有独立标题、封面色、画布尺寸、字体、字号、缩放、节点和关系。列表支持搜索、排序、复制、重命名和移入回收站。

### 6.2 编辑器

打开笔记后进入现有画布编辑器的演进版本：

- 自由拖动与无限/固定画布切换；
- 画布宽高预设与自定义；
- 字体、字号、节点颜色和层级样式；
- 便签、概念、问题、证据、图片节点；
- 文件选择和剪贴板图片导入；
- 图片既可成为独立节点，也可附着在便签内；
- 从资料库引用原文，并保留来源和定位；
- 自动保存、撤销/重做、缩放、框选、对齐和小地图。

返回知识网络时回到当前课程的笔记集合；返回课程主页时不退出课程。

## 7. 删除、回收站与恢复

课程删除改为“移入回收站”，默认保留 30 天：

- 移入后从正常书架隐藏；
- 课程内任务、资料、知识笔记、实验记录和图片保持完整；
- 回收站显示剩余保留天数；
- 支持恢复到书架和立即永久删除；
- 30 天到期后在应用启动或维护任务中清理；
- 永久删除需要二次确认，并明确展示将删除的数据类别。

知识笔记也使用同一软删除原则，但只在课程内回收站展示。课程被恢复时，其内部笔记状态保持不变。

## 8. 数据与路由架构

### 8.1 路由状态

前端增加明确的应用路由状态：

```text
/courses
/courses/:courseId/home
/courses/:courseId/dashboard
/courses/:courseId/roadmap
/courses/:courseId/knowledge
/courses/:courseId/knowledge/:notebookId
/courses/:courseId/library
/courses/:courseId/lab
/courses/:courseId/review
/courses/:courseId/settings
/settings
/trash
```

Electron 桌面端不依赖互联网路由，使用浏览器 History API 或等价本地状态路由。路径可恢复、可后退，并能保存每门课程最后访问位置。

### 8.2 数据模型

课程表增加：

- `cover_style`；
- `icon`；
- `goal`；
- `start_date`；
- `target_weeks`；
- `weekly_hours`；
- `progress`；
- `last_opened_at`；
- `deleted_at`；
- `purge_after`。

新增 `knowledge_notebooks`：

- `id`、`course_id`；
- `title`、`description`、`kind`；
- `cover_style`；
- `canvas_settings_json`；
- `created_at`、`updated_at`、`last_opened_at`；
- `deleted_at`。

现有知识节点和关系增加 `notebook_id`。迁移时为每门现有课程建立一个“默认知识画布”，把原节点和关系归入其中，确保旧数据不丢失。

### 8.3 API 边界

新接口使用显式课程路径，例如：

```text
GET  /api/courses/{courseId}/home
GET  /api/courses/{courseId}/notebooks
POST /api/courses/{courseId}/notebooks
GET  /api/courses/{courseId}/notebooks/{notebookId}/graph
```

后端必须同时校验 `courseId` 和 `notebookId` 的归属关系。旧的隐式 `active_course` 仅在迁移期用于兼容，完成改造后不作为业务查询的唯一依据。

## 9. 状态、错误与安全体验

- 书架、课程主页和笔记集合均提供骨架屏；
- 自动保存显示“保存中 / 已保存 / 保存失败待重试”；
- 创建课程失败保留表单内容；
- 打开损坏或不存在的课程时返回书架并显示可恢复提示；
- 图片上传失败不创建空节点；
- 离线本地服务异常时给出重连和诊断入口；
- 回收站清理采用事务与文件清理日志，数据库删除成功后不因单个锁定文件导致界面假失败。

## 10. 可访问性与键盘体验

- 所有书本、模块卡和笔记卡可使用键盘进入；
- 焦点样式清晰，弹窗关闭后恢复到触发元素；
- 动画可降低；
- 不仅依赖颜色表示进度或删除状态；
- 课程书架支持 `Ctrl+K` 搜索、`Ctrl+N` 新建课程；
- 画布继续支持删除、撤销、重做、缩放和粘贴快捷键。

## 11. 实施边界与顺序

本设计作为一个连续改造目标，但按可验证阶段交付：

1. 建立全局课程路由和书架入口；
2. 建立课程主页与新建课程向导；
3. 把所有模块挂入显式课程工作区；
4. 新增课程内多知识笔记并迁移旧画布；
5. 加入课程/笔记软删除与回收站；
6. 完成启动偏好、动画和恢复逻辑；
7. 全量回归、构建和桌面端端到端验证。

不在本轮范围内：云同步、多人协作、模板市场、移动端和多窗口课程并行编辑。

## 12. 验收标准

- 默认启动后第一屏是课程书架，而不是主驾驶舱；
- 可在设置中改为自动继续上次课程；
- 新建课程完成后进入该课程主页；
- 课程主页能进入所有当前课程模块；
- 返回书架不会混淆或丢失课程状态；
- 一门课程可创建多个独立知识笔记；
- 原有知识节点在迁移后仍可访问；
- 文件和剪贴板图片能进入指定笔记；
- 删除课程后进入回收站并可恢复；
- 跨课程 API 访问被拒绝；
- 键盘、降低动画、1366×768 和 1920×1080 视口可用；
- 后端、前端、构建、桌面冒烟和 Electron 端到端测试全部通过。
