# 知识笔记本书架与图片画布设计

## 产品目标

把“知识网络”从直接进入编辑器改为清晰的两层空间：用户先在课程书架中管理课程笔记本，再进入某一本笔记本的导图/自由画布。课程与笔记本保持同一数据实体，避免引入重复概念和迁移成本。

## 信息架构

1. **课程书架**：展示课程封面、最近更新时间、知识卡片数与连线数；支持创建、打开和删除。
2. **笔记本画布**：保留现有拖拽、缩放、导图连线、便签、闪卡和资料引用，新增返回书架、画布规格、字体和字号设置。
3. **图片工作流**：支持文件选择、网页/文件管理器复制后粘贴、桌面剪贴板读取。未选中便签时生成图片卡片；选中便签时把图片附着到便签。

## 数据与接口

- `Course` 列表增加 `node_count`、`edge_count`，供书架直接渲染概览。
- 新增 `DELETE /api/courses/{id}`。至少保留一个课程；删除活动课程后自动激活最近更新的剩余课程。
- 数据库升级到 schema v4：新增 `media_assets` 表，知识节点增加 `image_asset_id` 和 `image_alt`，节点类型增加 `image`。
- `POST /api/media/images` 接受 PNG/JPEG/WebP/GIF，限制 8 MB，按随机 UUID 保存到本地数据目录；`GET /api/media/images/{id}` 返回图片。
- 图片必须归属于当前活动课程；创建/更新节点时不能跨课程引用资产。
- 画布宽高、字体和字号保存在浏览器本地存储中，以课程 ID 隔离。该设置属于单机界面偏好，不污染可同步的知识内容。

## 交互与视觉

- 书架采用有厚度的笔记本封面而非普通后台卡片；封面按课程生成稳定配色，悬停时轻微抽出，打开时使用页面展开过渡。
- 新建笔记本是书架中的首个可操作对象，内联输入标题与描述，避免模态框打断。
- 删除入口默认隐藏在封面操作区，并使用原生确认，防止误删。
- 画布设置使用紧凑浮层：尺寸预设、自定义宽高、字体选择、字号缩放和恢复默认。
- 图片节点支持自适应预览、替代文字和选中状态；便签附件显示缩略图。
- 动效只使用 transform/opacity，提供 `prefers-reduced-motion` 降级，保持键盘焦点和高对比度可见。

## 边界与错误处理

- 只剩一本课程时禁用删除，并由后端返回 409 作为最终保护。
- 非图片、伪造扩展名、空文件和超限文件返回明确中文错误。
- 剪贴板没有图片时显示轻量状态提示，不创建空节点。
- 图片上传成功但节点创建失败时允许资产暂时孤立；后续备份清理流程可安全回收，不阻塞编辑。
- 画布尺寸调整不改变节点坐标，缩小时画布仍允许平移查看超出区域的节点。

## 验收标准

- 点击“知识网络”先看到书架，点击笔记本后才看到画布。
- 创建、打开、删除课程笔记本均能持久化；删除活动课程后应用仍保持可用。
- 图片文件与剪贴板图片均能成为图片卡片，也能附着到便签。
- 画布尺寸、字体、字号可调并在重启后按课程恢复。
- 后端测试、前端组件测试、生产构建和桌面启动检查全部通过。
