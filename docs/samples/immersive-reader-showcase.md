# StudyPilot 沉浸式 Markdown 阅读示例

> 这份资料用于验证连续阅读、自动排版、源码编辑、撤销/重做、缩放批注与知识图谱引用。

## 阅读器能力清单

- [x] Markdown 连续单页，不再按章节切成卡片
- [x] GitHub Flavored Markdown 表格与任务列表
- [x] 标题、引用、行内代码和代码块自动排版
- [x] 编辑后可撤销、重做
- [x] 支持双栏并排阅读
- [x] 批注坐标绑定资料块，缩放时同步变化

## 格式展示

| 功能 | 操作 | 预期结果 |
| --- | --- | --- |
| 目录 | 向下滚动 | 自动收起，阅读区扩大 |
| 缩放 | 点击 `＋` / `−` | 正文与圈画同步缩放 |
| 分栏 | 点击“分栏” | 第二份资料独立滚动 |
| 引用 | 选中文字 | 可发送到知识图谱 |

### 代码块

```python
def revision_status(can_undo: bool, can_redo: bool) -> str:
    return f"undo={can_undo}, redo={can_redo}"
```

### 学习笔记

1. 选择一段正文。
2. 添加高亮或便签。
3. 选择知识笔记并创建引用。
4. 从知识图谱节点返回时，阅读器会定位到对应资料块。

## 第二章节：长文滚动验证

沉浸式阅读器只保留阅读区自身的滚动条。标题栏和工具栏稳定显示，章节目录会在阅读开始后自动收起，避免外层页面与正文同时滚动。

修改本章节时，原始导入文件不会被覆盖；系统把每一次修改记录为修订。执行撤销后还可以重做，如果撤销后产生新的编辑，旧的重做分支会被安全清除。

圈画使用资料块内部的归一化坐标，并与正文放在同一个缩放层中。这样无论放大、缩小还是在双栏中查看，荧光笔、矩形和椭圆都不会相对正文漂移。
