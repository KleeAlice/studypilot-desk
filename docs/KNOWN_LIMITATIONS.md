# 已知限制

## P0 深度限制

- 项目、研究、论文、实验、错误、面试和周复盘共享通用持久化模型；可新增和查看，但领域专用表单、跨模块自动链接、统计视图与批量操作尚不完整。
- 知识画布已支持便签、记忆卡、引用、拖拽和思维分支，但还没有多人协作、手绘、富文本块、画布小地图和图片/PDF 导出。
- 文档高亮 API 已存在，桌面阅读器尚未提供接近专业 PDF 阅读器的分页、精确选区与批注体验。
- 学习/研究模板已从 DOCX 写入种子数据，但未全部转为可填写的引导式表单；周复盘不会自动生成所有后续任务。
- 多课程已可新建、切换并隔离画布/运行数据；课程复制、归档、排序和单课程导出仍未提供。
- Python 工作台是面向学习的本地 IDE，不是完整 VS Code：没有语言服务器、断点调试、包管理器、集成 shell 或扩展市场。
- Python 环境列表负责发现和选择本机已有解释器，不负责创建、删除或升级 Conda/venv。

## P1/P2 未实现

- 向量检索、混合召回/RRF、重排器和外部 AI 提供商。
- 全局剪贴板快捷键、悬浮专注窗、Git 深度集成、隐藏测试、Matplotlib 图形回传。
- EPUB、作品集一键生成、云同步、多端协作、插件市场和移动端。

## 技术限制

- Python 运行器不是安全沙箱，只适合可信本地代码。
- PDF 文本提取依赖文档内已有文本层，不内置 OCR；扫描件可能没有可搜索正文。
- FTS5 使用词项全文检索；中文连续文本的召回质量不等同于分词搜索或向量搜索。
- 恢复备份会替换当前数据库；虽自动建立恢复点，仍建议保留外部副本。
- 后端测试有一条 Starlette/httpx 依赖弃用警告；当前不影响功能，未来升级依赖时应清理。
- 当前未生成安装包或代码签名；交付方式是源码目录加一键启动脚本。
