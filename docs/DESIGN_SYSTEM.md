# 设计系统

## 视觉方向

界面采用“研究仪表台”而非通用 SaaS 卡片墙：细线边界、强层级数字、窄体标签、低饱和底色与少量蓝/橙/洋红状态色。标题栏和侧栏固定，主内容纵向滚动。

## 语义颜色

- `--bg` / `--panel`：画布与工作面。
- `--ink` / `--muted`：主文字与说明文字。
- `--accent`：可操作、当前和通过状态。
- `--warning`：阶段门和需关注状态。
- `--research`：项目/研究锚点。
- `--line`：分隔、输入边界和结构关系。

深浅主题均保持同一语义。主题可选深色、浅色、跟随系统，并持久化到设置。

## 布局与响应式

- 最小窗口 1100×700。
- 1366×768：完整侧栏与双列驾驶舱，不产生页面水平滚动。
- 1440×900 / 1920×1080：增加内容呼吸空间，不盲目放大字号。
- 降低动效偏好时禁用非必要过渡。
- 交互目标使用文字与状态共同表达，不只依靠颜色。

## 组件原则

- 页面头部回答“我在哪、当前周/阶段是什么”。
- 输入旁直接提供主要动作，错误留在上下文中。
- 空状态说明下一步能做什么。
- 阶段门、路线进度和交付物保持可追溯，不用装饰性图表代替事实。
