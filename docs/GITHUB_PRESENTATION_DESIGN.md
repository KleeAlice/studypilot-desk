# GitHub 项目展示设计

## 目标

把仓库首页从纯文字说明升级为可快速理解、可建立产品识别的项目门面。访问者应在首屏识别 StudyPilot Desk 是一个 Windows 本地优先桌面学习系统，并在继续滚动后理解它如何把课程、资料、AI 学习、知识沉淀、实验和复习连接成闭环。

## 已确认方向

- 视觉风格：产品展示型。
- 主视觉内容：品牌化界面插画，不使用真实用户截图。
- 文案语言：中文为主，配简短英文标语。
- 视觉素材：两张响应式 SVG。
- 信息密度：第二张 SVG 重点展示主要功能，而非只画抽象流程。

## 视觉资产

### 1. 品牌横幅

横向首屏图使用 StudyPilot Desk 的靛蓝与青绿色，配合轻量液态玻璃效果。画面由品牌标题、英文短标语、Windows / Local-first / AI-assisted 标签，以及两组应用界面插画组成：学习中心主窗口和资料书架侧卡。所有课程、资料和模型信息均为虚构演示内容。

### 2. 功能总览图

第二张图用六个界面分镜展示：

1. 课程与学习路线
2. 本地资料书架
3. AI 引导学习
4. 知识笔记与图谱
5. Python 实验室
6. 复习与学习统计

分镜之间以“导入 → 规划 → 学习 → 沉淀 → 验证 → 复习”的闭环连接。图中既保留产品界面感，也能独立作为功能流程图阅读。

## README 信息结构

1. 品牌横幅与一句话定位
2. Windows、本地优先、技术栈与状态徽章
3. 三个核心价值：聚合学习上下文、形成学习闭环、数据留在本机
4. 功能总览 SVG
5. 六个主要功能的精简说明
6. 一分钟启动
7. 技术架构与本地数据流
8. 验证命令、文档入口、隐私与当前项目状态

现有长功能清单会拆成可扫读的小节，保留准确性但减少首屏文字压力。

## GitHub About

- Description：使用简洁英文说明产品定位，避免与中文 README 重复。
- Topics：覆盖 Electron、React、FastAPI、SQLite、local-first、education、knowledge-management、AI assistant 与 Windows。
- Homepage：当前不填写，避免指向不存在的站点。

## 隐私与安全边界

- 不使用真实课程、资料、壁纸、模型配置、API 地址、密钥、本地路径或用户数据。
- SVG 不引用外部图片、字体、脚本或远程资源。
- 演示文字使用通用虚构内容，并在提交前扫描本地绝对路径与常见密钥模式。

## 验收

- 两张 SVG 均通过 XML 解析，并能在浏览器中独立打开。
- README 中所有相对链接均能解析到仓库内文件。
- 在 GitHub 实际仓库页检查首屏、图片缩放、移动端宽度逻辑和深色背景可读性。
- 检查仓库差异只包含展示相关文件，不上传临时构思稿或本地数据。
